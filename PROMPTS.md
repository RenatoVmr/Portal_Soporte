# Prompts de asistencia con inteligencia artificial



## Prompts utilizados

1. **Diagnóstico de conectividad:**  
   Analiza la comunicación entre el frontend React, la API ASP.NET Core y MySQL. Explica el orden de ejecución local y diagnostica errores de conexión como `Failed to fetch`, considerando que la base de datos se administra con MySQL Workbench.

2. **Mejora de interfaz:**  
   Mejora la interfaz del portal tomando como referencia la imagen proporcionada, sin reproducirla literalmente. Conserva las funciones existentes, elimina la barra lateral izquierda y adapta el diseño a distintos tamaños de pantalla.

3. **Revisión de requisitos de entrega:**  
   Revisa los requisitos de la entrega final y ayuda a completar los elementos pendientes. Conserva los diagramas, scripts SQL, procedimientos almacenados y datos ya preparados; no los reemplaces ni los recrees.

4. **Preparación para Railway:**  
   Configura el proyecto para desplegar el frontend y la API como servicios separados en Railway. Prepara los Dockerfiles y los ajustes de ejecución necesarios, documenta las variables de entorno y evita incluir credenciales en el repositorio.

5. **Conexión con la API desplegada:**  
   Diagnostica por qué el frontend desplegado no puede consultar la API. Verifica la URL de API configurada durante la compilación, el uso de dominios públicos, la configuración CORS y el proceso de reconstrucción del frontend.

6. **Configuración de MySQL en el entorno desplegado:**  
   Explica cómo conectar la API alojada en Railway con el servicio MySQL del mismo proyecto y cómo conectarse desde MySQL Workbench mediante los datos de conexión apropiados, distinguiendo entre direcciones privadas y públicas.

7. **Documentación del proyecto:**  
   Redacta instrucciones claras para instalar, ejecutar, probar y desplegar el portal, manteniendo la documentación coherente con la arquitectura y los artefactos existentes.

## Alcance de la asistencia

La asistencia se utilizó como apoyo para diagnóstico, generación y revisión de cambios, y documentación. Las decisiones de configuración, el código resultante y el despliegue deben ser revisados por el responsable del proyecto antes de su uso.
